01关于

我在物流快递企业和酒店负责过 Windows 终端、硬件、局域网、打印机、监控与业务设备的维护和故障处理。这些年最熟悉的，是员工真实的操作场景：设备哪里会坏、数据怎么流转、哪些重复劳动最耗人。

现在，我围绕实际需求拆解业务规则与流程，用 Codex、Claude 等工具辅助完成 Python 后端、Web 应用、API 集成、数据库、测试与部署。我重视成熟工具、业务标准化和实际交付。

对复杂工业算法、企业级基础设施和生产系统的深度运维，我会以项目实际要求、与专业人员协作、分阶段验证为前提，不夸大。

我的 AI 辅助开发方式

  1. 需求我负责梳理业务规则、拆解功能、定验收标准
  2. 编码Codex / Claude Code 辅助编码、调试、写测试
  3. 互审其他模型独立审查代码，驱动修复
  4. 验证单测、接口测试、回归测试，记录变更
  5. 验收真实数据实际操作，发现问题继续迭代
  6. 交付达标后发布，保留回滚与维护安排
